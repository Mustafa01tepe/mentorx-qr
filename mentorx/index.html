Automata Theory Tutor

MentorX Automata

A fine-tuned Socratic AI tutor for Automata Theory, guiding students through DFA, NFA, CFG, and Turing Machine concepts via question-based dialogue — never giving direct answers.

823
Questions
2,025

1,771
SFT Samples
  • Built on Qwen2.5-7B + QLoRA fine-tuning
  • Sources: TuringQ (810 Q) + LyTOC (13 Q)
  • LLM-as-Judge quality pipeline (Maverick)
  • Deployed on Modal with A10G GPU

DEEP
Deep Thinker
Explores concepts in depth, asks "why" questions. Needs challenging extensions beyond surface-level understanding.
MEM
Memorizer
Relies on memorization, struggles with applying concepts to new problems. Needs conceptual "why?" probing.
SEQ
Sequential Learner
Prefers step-by-step guidance, gets stuck on runtime errors. Needs structured, incremental scaffolding.
